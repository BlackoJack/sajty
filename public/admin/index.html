Админка

Заявки, цены, три позиции, контакты, имя, ссылка на пример и окна для гостей. Длинные тексты страницы здесь не правятся.

Имя видно внизу страницы. Ссылка открывается с карточки живого примера. Пустые поля ничего не показывают.

Пустое поле прячет кнопку на сайте. У Max нужны и подпись, и ссылка, либо оба поля пустые.

Telegram из облака часто не открывается, поэтому заявка дополнительно уходит письмом. Для Gmail нужен пароль приложения: аккаунт Google → безопасность → пароли приложений. Сервер smtp.gmail.com, порт 465. Для Яндекс Почты сервер smtp.yandex.ru, тот же порт. Пустой токен, chat id или пароль не стирают уже сохранённые.

На странице показывается одно окно: первое, которое гость ещё не закрыл. Если он нажимает «Забрать», код скидки или подарка прикладывается к заявке. Процент не больше 40, сумма не больше 20 000 ₽.
