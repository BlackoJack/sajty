Оповещение о заявке

Telegram из облака часто не открывается, поэтому заявка дополнительно уходит письмом. Для Gmail нужен пароль приложения: аккаунт Google → безопасность → пароли приложений. Сервер smtp.gmail.com, порт 465. Для Яндекс Почты сервер smtp.yandex.ru, тот же порт. Пустой токен, chat id или пароль не стирают уже сохранённые.
